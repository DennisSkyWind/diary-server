## 二、设计目标

### 2.1 核心目标
1. **减少无效边**：从8881条降到约500-800条
2. **提升标签质量**：每个标签都有语义价值
3. **人名统一**：同一人只用一个标签
4. **利用分类**：AI分类优先作为标签

### 2.2 质量指标
| 指标 | 目标值 |
|:---|:---|
| 高频标签文件数 | ≤15 |
| 单标签最大边数 | ≤105 (C(15,2)) |
| 标签种类 | 约100-150 |
| 无意义标签数 | 0 |

## 三、解决方案

### 3.1 标签提取策略重构

```
┌─────────────────────────────────────────────────────────┐
│                   标签提取流程                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 分类标签（优先级最高）                               │
│     ↓                                                   │
│  2. 专有名词识别（人名、地名、机构）                      │
│     ↓                                                   │
│  3. 关键词提取（TF-IDF + 词性过滤）                     │
│     ↓                                                   │
│  4. 停用词过滤                                          │
│     ↓                                                   │
│  5. 人名统一映射                                        │
│     ↓                                                   │
│  6. 频率控制（>15文件不建边）                            │
│     ↓                                                   │
│  7. 数量限制（每文件最多4个）                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 3.5 边数控制策略

```javascript
// 频率限制
const MAX_FILES_PER_TAG = 15;  // 单标签最多关联15个文件

// 判断是否应该为该标签创建边
function shouldCreateEdge(tag, fileCount) {
  // 停用词不创建
  if (GENERIC_STOPWORDS.has(tag)) return false;
  
  // 分词错误不创建
  if (SEGMENTATION_ERRORS.has(tag)) return false;
  
  // 频率过高不创建边（但标签可以保留）
  if (fileCount > MAX_FILES_PER_TAG) return false;
  
  return true;
}
```

## 六、风险评估

| 风险 | 影响 | 缓解措施 |
|:-----|:-----|:-----|
| 停用词过滤过度 | 丢失有效标签 | 保守添加，逐步测试 |
| 人名映射遗漏 | 部分人名未统一 | 收集反馈，持续补充 |
| 边数过少 | 图谱稀疏 | 可调整 MAX_FILES_PER_TAG |
| 分类标签不准确 | 标签质量下降 | 优先使用AI分类 |
